Start your fmwax house

Three steps, about ten minutes. Keep this page open until the last one. First time here? Read Start here for what you need: a free Cloudflare account and a free GitHub account.

1Your setup key

This is your house's password for setting it up. It was made in this browser just now, and nobody else has it.

…

This browser remembers the key, so you can come back to this page. Paste it into a note of your own too, in case this browser forgets it before you are done. Once your house is claimed, the key has done its work.

2Deploy to Cloudflare

Signed in to other Cloudflare or GitHub accounts in this browser? Then open this page in a private window, so your house can't land on the wrong account. (The key is made again there: use that one.)

Deploy to Cloudflare
  1. Sign in to Cloudflare. A form called Set up your application opens.
  2. Connect GitHub. Under Git account, click New GitHub connection, sign in, choose All repositories, then Install & Authorize.
  3. Cloudflare now shows "Select a repository". Don't pick anything there. Come back to this page and press Deploy to Cloudflare again. The form opens once more, with your GitHub account filled in.
  4. Change three things on the form, and leave the rest. The form scrolls inside its own box.
    Create private Git repositoryCheck this box.
    The two Select KV namespace boxesIn each, choose + Create new. Name the first fmwax-house-tokens and the second fmwax-house-programs.
    SETUP_KEYPaste your key from step 1.
  5. Click Deploy and wait about a minute, until the log ends with Success! Build completed. A few lines above that is your house's address. It looks like https://fmwax-house.your-name.workers.dev.

Pictures of the form, and what to do if the build fails: Start here, step 2.

3Open your setup page

Paste your house's address here. The button opens its setup page with your key already filled in: there, click Claim this house.
